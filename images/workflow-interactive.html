R session

You run the R code on your computer. It reads the data and produces results. You can edit the code yourself. If it fails, share an error message only after checking that it contains no restricted data.

Restricted data

These data stay in the approved local environment. The red interrupted arrow means the assistant must not read them. Check outputs before sharing: a table, log or error message can also contain restricted information.

Results

R produces the tables and plots. Only results cleared for release follow the green arrow to GitHub and can appear on the website. The numbers in this diagram are illustrative.

Browser or chat app

You talk to the assistant here, on the same computer as R. The language model runs in the cloud. Ask for code changes and discuss cleared outputs without giving it restricted data.

GitHub

The shared record holds the analysis plan, decision issues, code and change history. The assistant proposes a pull request. A person reviews and approves the change before it is merged. Named deciders settle scientific questions.

Cloud LLM + plugin

The assistant reads the project instructions, plan, questions and code. The plugin guides how it works. It proposes code changes; it does not decide the science or access restricted data.

Project website

Collaborators read explanations of the actual code and cleared results without running R. Building the website does not run the analysis. The repository supplies the material used to build it.
