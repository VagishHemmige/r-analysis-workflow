# R Analysis Workflow

A skills-only plugin for R biomedical analysis projects whose code and methods are published on GitHub with a Quarto website. It is not for R packages.

- Starting a project, or tidying an existing one: `initialize-analysis`.
- Joining or leaving a project: `onboard-collaborator`.
- Adding or changing a script: `document-analysis`, then `report-analysis` for tables and figures.
- Checking work before it is merged or published: `review-analysis`.

Ask in plain words; you don't need to name a skill. Installing grants no data access or GitHub permissions.

The plugin guides an assistant; it does not check your science. Review what it produces, as you would a new collaborator's work.

Install and update steps, dependencies, what has been tested and the source: https://github.com/VagishHemmige/r-analysis-workflow. Original text and code are MIT licensed (`LICENSE`).
